# v0.2.7 PC fire brief — training execution handoff

Cold-readable handoff for the home-PC session that fires the v0.2.7
training run. Mac orchestrator session (2026-05-25 PM) prepped all data
+ Modelfile + eval criteria; this brief is what the PC session reads to
execute training without re-thinking the scope.

## TL;DR

1. `git pull` on hammerstein-model + homelab
2. Run `scripts/v027_concat_sanitize.py` (PC writes from `v026_2_concat_sanitize.py` mirror) — produces `data/ray-stack-sft-v0.2.7-additions.jsonl`
3. Allocate RunPod A6000 (or RTX 4090 fallback) via `scripts/v027_fire_pod.py` (PC writes from `v026_2_fire_pod.py` mirror)
4. Pod trains + evals + ships GGUF + tears down
5. PC reviews eval scoreboard against `v0.2.7-eval-criteria-2026-05-25.md`
6. If gate clears, bump `homelab/.env MODEL=hammerstein-7b-v027`, restart bot, ping inbox
7. If gate fails, write verdict memo + leave v0.2.6.2 in production

Estimated end-to-end wall-clock: ~2-3 hours (pod allocation + training ~60-90 min + GGUF conversion + eval + cutover).
Estimated cost: $0.30-0.80 (single training run + eval pod time).

**Strip `_metadata` key before training.** The Mac orchestrator's JSONL files carry `_metadata` for human review; the trainer wants plain `{"messages": [...]}`. Add this to the sanitize step:

```python
for line in input_lines:
    rec = json.loads(line)
    # Strip _metadata if present
    rec.pop('_metadata', None)
    output_file.write(json.dumps(rec) + '\n')
```
